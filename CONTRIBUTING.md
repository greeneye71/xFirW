# Contribuire a xFirW

Il progetto è in fase iniziale. Prima di una modifica estesa, apri una issue per descrivere il problema o la funzione proposta; per correzioni circoscritte puoi proporre direttamente una pull request.

I contributi originali al codice e alla documentazione del progetto devono essere forniti sotto la stessa licenza **AGPL-3.0-only** indicata in [LICENSE](LICENSE). Mantieni le attribuzioni e includi soltanto materiale che hai diritto di contribuire. Non è richiesto il trasferimento del copyright al mantenitore.

Per ogni pull request:

- Spiega il problema risolto e il comportamento atteso.
- Indica le verifiche effettuate e gli eventuali limiti conosciuti.
- Usa dati sintetici o anonimizzati per esempi e test.
- Per nuove dipendenze, documenta scopo, licenza e compatibilità con la distribuzione prevista.
- Per modifiche all'impaginazione, confronta il PDF generato con il riferimento di test e controlla che nessun dato venga tagliato.

Non includere documenti di clienti, certificati privati, chiavi, token o altri segreti. I file reali usati localmente per l'analisi sono esclusi dal repository. Eventuali fixture XFIR o PDF pubbliche dovranno essere esplicitamente revisionate prima di essere aggiunte, anche quando sintetiche.

La richiesta di segnalazione dell'uso commerciale descritta in [COMMERCIAL_USE.md](COMMERCIAL_USE.md) è volontaria e non aggiunge condizioni alla licenza.
